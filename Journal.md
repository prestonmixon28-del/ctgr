# Journal
created a hashmap to store five species and their population counts. I added a search feature to find a species. A hashmap makees it easier to find information by their name.

added a text file to record animal sightings. The program reads each line and updates the population if the species already exists. If it is a new species, it adds it to the HashMap with a count of 1

added a feature to find the species with the hightest and lowest populations. The program checks each species and compares their counts. Looking up one species is faster than checking every species to find the hightest or lowest count.
